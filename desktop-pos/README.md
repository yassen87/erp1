# تطبيق سطح المكتب لنقطة البيع والكاشير (أوفلاين) — حمزة للعطور 🌸

تطبيق سطح مكتب مخصص لكاشير فروع **حمزة للعطور**، يعمل بدون إنترنت بنسبة 100% مع مزامنة سحابية تلقائية فور عودة الاتصال.

---

## ✨ المميزات الرئيسية
1. **يعمل 100% بدون إنترنت (Offline-First):**
   - بيع الأصناف المباشرة والزيوت والعطور والوصفات الجاهزة والعروض.
   - مسح الباركود باستخدام الماسح الضوئي مع صوت تنبيه إلكتروني (Beep) فوري.
   - تركيب العطور الفورية (تفصيل بالجرامات واختيار الزجاجة وحساب الأسعار والتكلفة).
   - تسجيل عملاء جدد وحفظ بياناتهم محلياً.
2. **خصم المخزون المحلي فورياً:**
   - يخصم رصيد المنتج والزيت من قاعدة البيانات المحلية للجهاز فور إصدار الفاتورة حتى لا يبيع الكاشير بالخطأ صنفاً نفد رصيده أثناء انقطاع النت.
3. **مزامنة ذكية ثنائية الاتجاه مع السيرفر السحابي (Cloud Sync):**
   - رفع الفواتير المعلقة في الخلفية تلقائياً بمجرد توفر النت.
   - سحب أحدث الأسعار والمنتجات والأرصدة من السيرفر.
   - نظام حماية ضد تكرار الفواتير (Idempotency عبر UUID فريد لكل فاتورة).
4. **طباعة الإيصالات الحرارية (80mm Thermal Receipts):**
   - إيصال حراري احترافي منسق يحمل شعار وهوية حمزة للعطور وتفاصيل الأصناف والفرع والمبالغ والدين.
   - يدعم الطباعة الصامتة المباشرة إلى طابعة البونات.
5. **مؤشر حالة الاتصال المباشر (Status Badge):**
   - 🟢 متصل بالسحابة (مزامنة فورية)
   - 🟡 يعمل أوفلاين (يظهر عدد الفواتير المعلقة المحفوظة محلياً)
   - 🔄 زر مزامنة يدوي فوري بضغطة زر واحدة.

---

## 🚀 طريقة التشغيل

### تشغيل فوري (بدون أي خطوات إضافية):
فقط اضغط دبل كليك على الملف:
📁 **`تشغيل_الكاشير_اوفلاين.bat`**

سيعمل البرنامج مباشرة في نافذة تطبيق مستقلة (Desktop App Mode) بكامل مميزاته.

### لتثبيت محرك Electron للطباعة الحرارية الصامتة (اختياري):
اضغط دبل كليك على:
📁 **`تثبيت_المتطلبات.bat`**
ثم شغل:
📁 **`تشغيل_الكاشير_اوفلاين.bat`**
